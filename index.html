Contrôle humain

Regarder chaque asset, puis trancher.

Choisissez le dossier qui contient vos fichiers .glb et .gltf. Les sous-dossiers sont inclus. Un seul modèle est affiché à la fois. Après chaque vote, le suivant arrive. Rien n’est effacé sur le disque : les décisions remplissent un classeur Excel.

On garde L’asset reste dans la bibliothèque.
On étudie À revoir, trop tôt pour décider.
On supprime Marqué pour suppression. Le fichier reste en place.

Vous pouvez aussi déposer un dossier dans la fenêtre. La souris reprend les réflexes de F3D : clic gauche pour tourner, clic droit pour déplacer, molette pour zoomer.

Comment voter

Le vote enregistre la décision puis passe au fichier suivant. Le modèle 3D n’est ni déplacé ni effacé.

  • G On garde
  • E On étudie
  • S ou Suppr On supprime
  • 1 2 3 du pavé numérique, dans le même ordre
  • ← → fichier précédent ou suivant, sans voter
  • Ctrl + Z annule le dernier vote
  • R ou double-clic recadre la vue
  • Espace lecture ou pause des animations
  • W fil de fer · L grille · H cette aide

Clic gauche : tourner. Clic droit ou molette appuyée : déplacer. Molette : zoomer. Le classeur revue-assets.xlsx est écrit dans le dossier .gf-revue, à côté d’une session qui permet de reprendre.
